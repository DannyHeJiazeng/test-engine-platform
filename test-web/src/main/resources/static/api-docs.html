📘 Test Engine Platform API 文档

RESTful API 接口文档 - 版本 1.0.0

🧪 测试执行 API

POST /api/test/run
执行测试用例
{
  "packagePath": "com.example.functional",
  "groups": ["functional"],
  "checkQualityGate": true
}
GET /api/test/status/{executionId}
查询执行状态
GET /api/test/history
获取执行历史

⚡ 性能测试 API

POST /api/performance/run
执行性能测试
{
  "url": "http://localhost:8080/api/users",
  "threads": 50,
  "rampUpSeconds": 10,
  "durationSeconds": 120
}
POST /api/performance/run/concurrency
并发测试
url=http://localhost:8080&concurrency=100
POST /api/performance/run/gradual
梯度并发测试
GET /api/performance/result/{testId}
获取性能测试结果

🔍 巡检管理 API

GET /api/inspection/tasks
获取所有巡检任务
POST /api/inspection/tasks
创建巡检任务
{
  "taskId": "daily-health-check",
  "packagePath": "com.example.inspection",
  "intervalSeconds": 300
}
DELETE /api/inspection/tasks/{taskId}
删除巡检任务
POST /api/inspection/tasks/{taskId}/execute
立即执行巡检任务
GET /api/inspection/health-checks
执行健康检查
GET /api/inspection/alerts
获取告警历史

🚪 质量门禁 API

GET /api/quality-gate/status
获取质量门禁状态
GET /api/quality-gate/history
获取质量门禁历史
GET /api/quality-gate/threshold/default
获取默认阈值配置

📋 报告 API

GET /api/report/{executionId}
获取测试报告
GET /api/report/{executionId}/html
获取 HTML 报告
GET /api/report/summary
获取汇总报告
GET /api/report/trend
获取趋势报告
